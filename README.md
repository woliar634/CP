## 📖 Overview

This repository contains my **Competitive Programming** solutions written in **C++**. The problems are collected from online judges and organized by topic to strengthen problem-solving skills, algorithmic thinking, and programming fundamentals.

The repository covers beginner to intermediate problems involving arrays, strings, mathematics, bit manipulation, searching, sorting, and implementation challenges from platforms such as **Codeforces**.

# 🚀 Getting Started

1. Clone the repository.

```bash
git clone https://github.com/woliar634/CP.git
```

2. Open any `.cpp` file.

3. Compile the program.

```bash
g++ filename.cpp -o output
```

4. Run the executable.

```bash
./output
```
